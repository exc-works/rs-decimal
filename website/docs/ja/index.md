# 正確な値と明確な動作

rs-decimal は十進数の係数、小数点以下の桁数、初期化状態を保持します。通常の使い方から始めて、丸め、末尾のゼロ、エラーの動作を確認できます。

::: info ライブラリを調べる
全355件のAPI項目に8言語のドキュメントを用意しています。メソッドのページでは通常の使い方と注意点を説明し、Rustの例を共有します。ブラウザー対応メソッドはRust/Wasm bridgeで実行し、ネイティブ専用の連携は明示します。
:::
