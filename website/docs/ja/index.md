# 正確な値と明確な動作

rs-decimal は十進数の係数、小数点以下の桁数、初期化状態を保持します。通常の使い方から始めて、丸め、末尾のゼロ、エラーの動作を確認できます。

::: info ドキュメントのプレビュー
多言語サイトは構築中です。API 一覧では予定と実装済みを区別します。言語別の画面があっても、すべてのメソッドが翻訳済み、または実行可能とは限りません。
:::
