# 用語集

| 用語 | 意味 |
| --- | --- |
| coefficient（係数） | 数字を保持する任意精度の符号付き整数。 |
| scale（小数点以下の桁数） | 非負の桁数。値 = 係数 × 10^−scale。 |
| precision（精度） | 通常は小数点以下の桁数。有効数字を扱うメソッドでは単位を明示します。 |
| rounding（丸め） | 捨てる数字が結果に影響するときに適用する規則。 |
| initialized（初期化済み） | 初期化済みの値と既定の未初期化ゼロを区別します。 |
| valid（有効性） | 初期化や数値ゼロとは独立した nullable 値の存在フラグ。 |
| exact（正確） | 情報が失われていないこと。変換では正確性フラグを別に返す場合があります。 |

メソッド名とエラー識別子はどの言語でも元の表記を使います。言語を切り替えても入力構文は変わらず、カンマを小数点へ自動変換しません。
