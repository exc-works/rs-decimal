# プレイグラウンド

Rust と同名のメソッドを JavaScript で呼び出せます。実行して正確な値と状態を確認します。

<script setup>
import Playground from "../_components/Playground.vue";
import { locales } from "../../locales.mjs";
</script>

<Playground locale="ja" :labels="locales['ja']" />

各メソッドのページでは、共通の例に含まれるリテラル引数をフォームで編集できます。パラメーターは JavaScript の呼び出し順に並び、Rust のメソッド名と引数の順序を保持します。生成されたコードをこのエディターで開き、複雑な値を編集したり呼び出しを追加したりできます。メソッドページの期待される状態は元の例に対応します。同じタブで言語を切り替えてもフォームの編集内容は保持されます。

共有機能は最大 4 KiB の UTF-8 コードとライブラリのビルドコミットを URL フラグメントに格納します。コードはサーバーにアップロードされません。共有リンクには同じビルドが必要です。読み込み時に以前の結果を消去しますが、自動実行はしません。無効なリンクでは現在の下書きを保持します。コードを確認してから実行してください。大きなスクリプトはファイルにエクスポートしてください。エディターは最大 64 KiB に対応します。リンクにはスクリプト内のテキストが含まれるため、共有前にコードを確認してください。
