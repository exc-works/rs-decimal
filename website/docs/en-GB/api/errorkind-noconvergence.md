# ErrorKind::NoConvergence

Identify NoConvergence failures.

```rust
NoConvergence
```

## Parameters, return and normal usage

The bounded algorithm could not certify a rounded result; this does not mean the mathematical result does not exist. ErrorKind is a stable category rather than a message string. Browser enum values are Rust variant names; constructed errors use matches(), while caught bridge exceptions expose a kinds array.
