# 용어집

| 용어 | 의미 |
| --- | --- |
| coefficient (계수) | 숫자를 저장하는 임의 크기의 부호 있는 정수입니다. |
| scale (소수 자릿수) | 음수가 아닌 소수 자릿수로, 값 = 계수 × 10^−scale입니다. |
| precision (정밀도) | 보통 소수 자릿수이며, 유효 숫자 메서드는 별도 단위를 명시합니다. |
| rounding (반올림 방식) | 버린 숫자가 결과에 영향을 줄 때 적용하는 규칙입니다. |
| initialized (초기화됨) | 초기화된 값과 기본 미초기화 0을 구분합니다. |
| valid (유효성) | 초기화나 숫자 0과 무관한 nullable 값의 존재 플래그입니다. |
| exact (정확함) | 정보가 손실되지 않았음을 뜻하며 변환은 별도 정확성 플래그를 반환할 수 있습니다. |

모든 언어에서 메서드 이름과 오류 식별자를 유지합니다. 언어 선택은 입력 문법을 바꾸지 않으며 쉼표를 소수점으로 자동 변환하지 않습니다.
