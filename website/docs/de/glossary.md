# Glossar

| Begriff | Bedeutung |
| --- | --- |
| coefficient (Koeffizient) | Vorzeichenbehaftete Ganzzahl beliebiger Größe mit den Ziffern. |
| scale (Skala) | Nicht negative Anzahl der Nachkommastellen: Wert = Koeffizient × 10^−scale. |
| precision (Präzision) | Meist Nachkommastellen; Methoden für signifikante Stellen nennen ihre andere Einheit. |
| rounding (Rundung) | Regel für verworfene Ziffern, die das Ergebnis beeinflussen. |
| initialized | Unterscheidet initialisierte Werte von der nicht initialisierten Standardnull. |
| valid | Anwesenheitskennzeichen eines nullable Werts, unabhängig von Initialisierung und numerischer Null. |
| exact (exakt) | Kein Informationsverlust; Konvertierungen können ein separates Genauigkeitskennzeichen liefern. |

Methodennamen und Fehlerkennungen bleiben in allen Sprachen unverändert. Die Sprache ändert nicht die Eingabesyntax: Ein Komma wird nicht stillschweigend zum Dezimalpunkt.
