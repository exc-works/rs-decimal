# Glossaire

| Terme | Signification |
| --- | --- |
| coefficient | Entier signé de taille arbitraire contenant les chiffres. |
| scale (échelle) | Nombre non négatif de décimales : valeur = coefficient × 10^−scale. |
| precision (précision) | Généralement le nombre de décimales ; les méthodes de chiffres significatifs précisent leur unité. |
| rounding (arrondi) | Règle appliquée lorsque les chiffres supprimés influencent le résultat. |
| initialized | Distingue les valeurs initialisées du zéro non initialisé par défaut. |
| valid | Indicateur de présence nullable, indépendant de l’initialisation et du zéro numérique. |
| exact | Aucune information perdue ; certaines conversions renvoient un indicateur d’exactitude. |

Les noms des méthodes et identifiants d’erreur restent inchangés. La langue ne modifie pas la syntaxe décimale acceptée : la virgule n’est pas automatiquement remplacée par un point.
