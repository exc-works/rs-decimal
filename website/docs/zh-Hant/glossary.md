# 術語表

| 術語 | 含義 |
| --- | --- |
| coefficient（係數） | 儲存數字的任意大小帶正負號整數。 |
| scale（小數位數） | 非負的小數位數：數值 = 係數 × 10^−scale。 |
| precision（精度） | 方法參數中通常表示小數位數；有效位數方法會說明不同單位。 |
| rounding（捨入） | 捨棄的數字影響結果時採用的規則。 |
| initialized（已初始化） | 區分初始化值與預設的未初始化零。 |
| valid（有效性） | 可空值的存在旗標，獨立於初始化狀態與數值零。 |
| exact（精確） | 沒有遺失資訊；轉換方法可能另行回傳精確性旗標。 |

各語言都保留原始方法名稱與錯誤識別碼。切換語言不會改變十進位輸入語法，也不會自動將逗號轉成小數點。
