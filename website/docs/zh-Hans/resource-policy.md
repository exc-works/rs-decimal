# Playground 资源限制

浏览器 bridge 的允许范围小于 Rust 库。`BridgeError` 的 `category: "resource"`
表示达到 Playground 配额，不是数值库错误。在限制内，方法名、参数顺序和计算
结果保持 Rust 行为；核心库没有修改。

| 限制 | 当前值 |
| --- | --- |
| 十进制输入 | 8192 个 UTF-8 字节；尾数及指数展开后的系数最多 4096 位 |
| 存储 scale 及输入 scale 的绝对值 | 1000 个小数位 |
| 结果系数的保守估计 | 16384 位二进制数，最多 4933 位十进制数 |
| 二进制/BSON 和 ByteBuffer 输入 | 65536 字节 |
| 验证规则/错误列表及消息映射 | 64 项；每个字符串 8192 字节；JSON 传输 65536 字节 |
| 验证翻译文本 | 翻译前保守估计总计 65536 字节 |
| 单个 Wasm 实例的调用次数 | 10000，包含 getter、快照和元数据读取 |
| 非平凡根的 degree | 128 |
| 对数/指数输出精度、输入 scale、系数 | 128 位小数、256 位小数、4096 个二进制位 |
| 普通 exp 输入绝对值 | 64（保留可证明舍入为零的负输入快速路径） |
| 构建产物的 Wasm 线性内存上限 | 64 MiB |

配置转换检查原始小数文本及解码后的 JSON 字符串；128 位整数变体在传输前
验证精确的有符号或无符号范围。通用 Serde 适配器保留其错误接口，并拒绝浮点 visitor。
SQL scan 在按核心规则去除外围引号后检查文本。验证规则在构造前检查小数参数，
翻译前限制重复占位符展开；字段及插入参数始终按字面文本处理。
文本、参数及 JSON 解码将源输入限制为 8192 字节，并在修改接收者前检查解码后的
小数文本，包括 JSON 转义。JSON 原始数字字节保持精确，不经过 JavaScript number。
YAML/XML 源输入最多 8192 字节；核心数值解析前检查已解码的标量或元素文本，
包含转义、CDATA、YAML 下划线归一化及浮点补零。YAML 标量最多 4096 个
十六进制数字字符，以保守限制进制整数分配。
二进制解码在分配 BigInt 前限制实际系数位数和编码中的 scale。BSON 字符串遵循文本
限制；Decimal128 指数展开在核心解析前检查。解码预检查失败均保留接收者状态。

Rust wrapper 在解析前检查指数展开和 scale；精确乘法检查 scale 之和，舍入乘法
检查输出 scale，两者都在计算前检查中间系数位数。加减法检查对齐增长及进位，
除法在分配前检查分子或分母的缩放。商余数运算在零除数检查后检查对齐。幂运算
限制规范化后的中间精度、系数增长及倒数缩放；保留核心零值、正负 1 的快速路径
及分配前的 Overflow。消耗型算术即使预检查失败也会消耗接收者。精确有理数转换检查约分后的分母因子及
系数增长，舍入有理数转换在乘法前检查分子缩放。构造有理数前先拒绝零分母。
格式化限制宽度（65536 字节）、precision（1000）及定点系数增长。追加在修改前
检查已有缓冲区长度加保守文本长度，可能拒绝实际刚好可容纳的操作。
根运算在调用核心前限制缩放、Newton 幂及精确中点验证的中间值。非平凡 degree
最多为 128；零、正负 1 和一次根保留快速路径，仍须符合输出精度限制。
对数和指数使用更严格的输入及精度预算，以约束有理数约分和所有区间细化重试，
包括核心最多 8192 个保护位。exp 还限制普通输入绝对值；足够负且核心可证明
舍入为零的输入保留安全快速路径。
核心能在分配前拒绝的负精度及零除数保留
原有库错误。rescale 及指定精度的舍入在分配十次幂前检查目标 scale 和系数增长。shift
检查结果的 scale 和系数增长；有效数字舍入预留可能的进位。如果核心能在分配前
返回 shift 溢出，则保留该库错误。因此连续调用不能绕过
单次限制生成无限增长的值，格式化输出也受值的范围约束。保守估计可能拒绝最终
结果较小的操作，例如与零相乘；这属于 Playground 策略，不是核心库规则。
若输入没有独立触及资源限制，错误语法、负 precision 和未知舍入模式仍由库报告。

消耗所有权的方法即使因 Rust 资源检查失败，也会消耗接收者；借用参数保持不变。
耗尽调用预算后，除释放对象外的导出调用持续失败，重新创建 JS facade 不会重置
预算；新建 Wasm 实例才会重置。

JS facade 在 wasm-bindgen 复制输入前检查字符串和字节数组长度，Rust 在调用核心
库或再次分配前重新检查切片。直接调用原始 ABI 会先产生参数的临时副本，但不能
取消产物的线性内存上限；runner 必须隐藏原始 ABI。这不等于 JavaScript 堆或整个
浏览器进程的硬内存配额。runner 已提供 Worker 终止、源代码及输出限制，以及网络隔离。

本地 Node 26 测量中，解析并读取 4096 位系数及格式化 scale 为 1000 的值约需
1.2 ms，仅作为开发测量，不是延迟承诺。CI 记录相同测量并验证拒绝边界。
开发 Wasm 产物约 196 KB，gzip 后约 73 KB；最终提交的准确大小、哈希和内存
上限以 `build.json` 为准。
