# 术语表

| 术语 | 含义 |
| --- | --- |
| coefficient（系数） | 保存数字的任意大小有符号整数。 |
| scale（小数位数） | 非负的小数位数：数值 = 系数 × 10^−scale。 |
| precision（精度） | 方法参数中通常表示小数位数；有效数字方法会明确使用不同单位。 |
| rounding（舍入） | 丢弃的数字影响结果时采用的规则。 |
| initialized（已初始化） | 区分初始化值与默认的未初始化零。 |
| valid（有效性） | 可空值的存在标志，独立于初始化状态和数值零。 |
| exact（精确） | 没有丢失信息；转换方法可能单独返回精确性标志。 |

各语言都保留原始方法名和错误标识。切换语言不会改变十进制输入语法，不会自动将逗号转成小数点。
